# Progress Spinner

Use a spinner for a compact activity indicator. value=null is indeterminate; finite values are clamped to min/max for display with a development warning when outside the range. Invalid ranges and non-finite values throw. A non-empty label is required. Determinate progress exposes aria-valuenow; indeterminate omits it. Reduced motion uses a gentle opacity pulse instead of rotation. Pair long-running activity with visible explanatory text.

## Import and minimum example

```ts
import {
  AtralumeProgressSpinner,
  AtralumeProgressSpinnerHarness,
} from "@atralume/angular/progress";
```

```html
<atr-progress-spinner label="Loading profile" />
```

## Customization and component tokens

Functional variants are stable inputs; component tokens control visual details. A theme supplies semantic color decisions, a surface supplies the background context, and an instance override changes one composition. Import `@atralume/angular/styles/theme.css` once, including for directive styles. Do not create CSS-valued inputs.

The public token manifest at `@atralume/angular/styles/tokens.json` lists every token. This atom uses the `--atr-comp-progress-*` namespace, including color, size or spacing, shape and motion where applicable.

```css
.my-example {
  --atr-comp-progress-height: 1rem;
}
```

Overrides inherit globally, through nested themes and surfaces, or from a consumer class. Specific appearance colors can be overridden through appearance-specific tokens documented in the manifest; defaults resolve from system tokens.

Glass uses the existing backdrop and opaque fallback; atoms do not apply their own backdrop filter. Verify contrast against the final composited background.

## Common mistakes

Avoid replacing native semantics, encoding information by color alone, removing accessible names, or relying on a tooltip for a label. Do not import internal paths or include Storybook in the application runtime. Use the exported harness for observable host state.
