# Truncated Text

Use Truncated Text when long copy must fit a fixed number of lines. Pass the
full string through `content`. Optional hints surface overflow without custom
measurement.

Composition over Taiga UI
[`TuiLineClamp`](https://taiga-ui.dev/components/line-clamp) (LineClamp).

## Import

```ts
import { AtralumeTruncatedText } from "@atralume/angular/truncated-text";
```

```html
<atr-truncated-text [content]="description" [lines]="2" [lineHeight]="24" />
```

## API and behavior

`lines` maps to Taiga `linesLimit`. `showHint` controls the overflow hint.
Listen to `overflownChange` when layout must react to clamp state.

## Tokens

Override text color with `--atr-comp-truncated-text-color` when needed.
