# Popover

Thin adapter over Taiga `TuiDropdown`. Apply `[atrPopover]` on the trigger and pass panel content as a `TemplateRef`. Popover holds interactive content; Tooltip is brief noninteractive help. Use `panelRole` (maps to `tuiDropdownRole`) when the content calls for a dialog/listbox role. Labels name the dropdown host for assistive tech.

**Breaking (Ola 5):** removed split `atr-popover` panel + `atrPopoverTriggerFor` + Atralume overlay engine. Trigger-hosted Taiga dropdown replaces connected overlay positioning, backdrop, and focus options (`focus` / `restoreFocus` / `hasBackdrop` / `arrow` / `origin` dropped).

Taiga UI reference: [Dropdown](https://taiga-ui.dev/directives/dropdown).

## Import and composition

```ts
import { AtralumePopover } from "@atralume/angular/popover";
```

```html
<button
  atrButton
  atrPopover
  [atrPopover]="panel"
  [(opened)]="opened"
  panelRole="dialog"
  label="Edit details"
>
  Open details
</button>
<ng-template #panel>
  <div class="atr-popover-content">…</div>
</ng-template>
```

## Themes, glass, tokens and consumer overrides

Import `@atralume/angular/styles/theme.css` once. Appearance `atr-popover` styles `tui-dropdown` via `--atr-comp-popover-*` tokens.

## Common mistakes

Do not keep a parallel overlay engine for popovers. Do not use Menu for selecting a form value.

| `AtralumePopover` | `popoverEnabled` | `Input` | `boolean`                                 | `true`     |
