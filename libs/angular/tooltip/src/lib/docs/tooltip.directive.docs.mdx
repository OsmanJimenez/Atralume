# Tooltip

Use brief, noninteractive text. A tooltip does not replace the trigger name; interactive content belongs in a Popover. Hover/focus show the panel after showDelay and hide after hideDelay. Supply a stable unique tooltipId for consumers that still bind `aria-describedby`.

The adapter applies Taiga UI `TuiHintDirective` via `hostDirectives`, forwarding `atrTooltip`, `showDelay`, and `hideDelay`. The `position` input remains for API stability; Taiga hint default direction applies unless consumers configure hint options. Keep the `atrTooltip` selector; do not add `tuiHint` on the same host.

Taiga UI reference: [Hint](https://taiga-ui.dev/directives/hint).

## Import and API

Import public components, directives, services and types from `@atralume/angular/tooltip`. See the exported TypeScript interfaces for all configuration options. No CDK type is required in consuming templates or service calls. The executable demo source shows component/template composition and typed results.

## Accessibility, keyboard and focus

Use brief, noninteractive text. A tooltip does not replace the trigger name; interactive content belongs in a future Popover. Hover/focus show the panel after showDelay and hide after hideDelay. The panel remains hoverable. Touch toggles the description without suppressing the native action; a later outside touch or Escape dismisses it. Supply a stable unique tooltipId. Only one tooltip remains open per theme context.

Escape dismisses the top overlay before lower overlays. Focus must return to a connected origin when configured. Keep visible names and labels independent of overlays. Check Tab and Shift+Tab through modal content and preserve a clear dismissal action.

## Context propagation and personalization

The shared infrastructure captures the nearest theme, surface and density attributes, direction and only `--atr-sys-*`, `--atr-comp-*`, `--atr-ref-*` custom properties. It does not copy all computed styles. Explicit contextClasses support consumer theme classes. System color preference refreshes modal contexts. Open a new panel or refresh consumer composition after changing arbitrary runtime brand overrides.

Import `@atralume/angular/styles/theme.css`; it includes CDK structural overlay CSS. Component tokens use `--atr-comp-tooltip-*`. Consumers control brand through tokens, functional choices through typed configuration. Glass belongs to the originating context and has an opaque fallback. Z-index roles and stack offsets are shared system tokens.

```css
.custom {
  --atr-comp-tooltip-shape: 1.5rem;
}
```

## Responsive, RTL, motion and common mistakes

Logical positioning and viewport collision fallback support RTL and small viewports. Dynamic viewport limits and safe areas avoid covering all content. Reduced motion has no nonessential panel animation; forced colors preserves boundaries. Do not nest interactive content in tooltips, use menus for route navigation, or remove modal labels. Do not create a second Modal or Toast service. Server calls return closed references and do not attach browser overlays; trigger-created overlays clean up with their owner.
