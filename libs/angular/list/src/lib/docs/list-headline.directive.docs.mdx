# List Headline

Use `AtralumeListHeadline` as part of the List composition. Import it from `@atralume/angular/list`. This companion documents the public slot or subcomponent; the parent [List documentation](?path=/docs/composition-list--docs) contains the complete usage, variants and executable composition.

## Composition and API

Preserve the native element for directives. Project content through the named slot; do not add interactive wrappers around existing controls. Component inputs and signal contracts are defined in the adjacent TypeScript source. Parent composition determines selection, focus and overlay lifetime.

## Accessibility, states and focus

Keep native labels and meaningful text. Use the parent's keyboard contract for interactive parts. Slots do not change native roles. Disabled behavior belongs to the native control or the parent family. Use stable unique IDs for ARIA associations. Refer to the parent Keyboard story for navigation and restoration.

## Tokens, themes and overrides

The component uses the parent's `--atr-comp-list-*` token namespace. Import the public theme stylesheet once. Global, scoped and instance overrides work with light/dark, nested themes and glass. Functional states are inputs; brand values use CSS custom properties.

```css
.custom {
  --atr-comp-list-gap: 1rem;
}
```

## Responsive, RTL, motion and common mistakes

Use logical layout and preserve reading order across responsive modes. The parent handles RTL, forced colors and reduced motion. Avoid duplicating native events, introducing invalid nested buttons, or treating a structural slot as a new widget.
