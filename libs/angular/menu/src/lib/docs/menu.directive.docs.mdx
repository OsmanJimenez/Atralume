# Menu

Menus are commands, not site navigation. Native buttons use menuitem, menuitemcheckbox or menuitemradio behavior through public CDK host directives. Arrow keys, Home/End, typeahead, Escape, submenus, RTL and focus restoration come from CDK Menu. Use invoked for a command; disabled items do not invoke it. Group radio items with atrMenuGroup.

Item appearance is adapted with Taiga UI `TuiOption` (`hostDirectives` + `tuiOption`). Menu behavior stays on Angular CDK Menu because Taiga `TuiDataList` targets select/combobox lists rather than a full menu trigger contract.

Taiga UI reference: [DataList](https://taiga-ui.dev/components/data-list).

## Import and API

Import public components, directives, services and types from `@atralume/angular/menu`. See the exported TypeScript interfaces for all configuration options. No CDK type is required in consuming templates or service calls. The executable demo source shows component/template composition and typed results.

## Accessibility, keyboard and focus

Menus are commands, not site navigation. Native buttons use menuitem, menuitemcheckbox or menuitemradio behavior through public CDK host directives. Arrow keys, Home/End, typeahead, Escape, submenus, RTL and focus restoration come from CDK Menu. Use invoked for a command; disabled items do not invoke it. Group radio items with atrMenuGroup.

Escape dismisses the top overlay before lower overlays. Focus must return to a connected origin when configured. Keep visible names and labels independent of overlays. Check Tab and Shift+Tab through modal content and preserve a clear dismissal action.

## Context propagation and personalization

The shared infrastructure captures the nearest theme, surface and density attributes, direction and only `--atr-sys-*`, `--atr-comp-*`, `--atr-ref-*` custom properties. It does not copy all computed styles. Explicit contextClasses support consumer theme classes. System color preference refreshes modal contexts. Open a new panel or refresh consumer composition after changing arbitrary runtime brand overrides.

Import `@atralume/angular/styles/theme.css`; it includes CDK structural overlay CSS. Component tokens use `--atr-comp-menu-*`. Consumers control brand through tokens, functional choices through typed configuration. Glass belongs to the originating context and has an opaque fallback. Z-index roles and stack offsets are shared system tokens.

```css
.custom {
  --atr-comp-menu-shape: 1.5rem;
}
```

## Responsive, RTL, motion and common mistakes

Logical positioning and viewport collision fallback support RTL and small viewports. Dynamic viewport limits and safe areas avoid covering all content. Reduced motion has no nonessential panel animation; forced colors preserves boundaries. Do not nest interactive content in tooltips, use menus for route navigation, or remove modal labels. Do not create a second Modal or Toast service. Server calls return closed references and do not attach browser overlays; trigger-created overlays clean up with their owner.
