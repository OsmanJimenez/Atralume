# Atralume

Accessible Angular design system — components, DTCG tokens, and themes with a
brand API on top of Taiga UI 5.

**npm:** [`@osmanjimenez/atralume`](https://www.npmjs.com/package/@osmanjimenez/atralume)
· **version:** `0.2.0` (preview)
· **source:** [GitHub](https://github.com/OsmanJimenez/Atralume)

> Public APIs may evolve before `1.0.0`. See component maturity in the repository docs.

## Principles

- Accessible by default, with native semantics where it matters
- Composable and token-driven (DTCG → CSS variables)
- Themeable with `data-atr-theme` and `data-atr-surface` (including glass)
- Documented through executable Storybook examples

Light, dark, system, nested themes, and glass share the same generated token
contract. Start with **Getting Started**, then **Theming** and **Foundations**.

## Install

```bash
npm install @osmanjimenez/atralume @taiga-ui/core @taiga-ui/cdk @taiga-ui/kit
```

Call `provideAtralume()` once, mount `<tui-root>`, and import
`@osmanjimenez/atralume/styles/theme.css` (or the Sass entry).
