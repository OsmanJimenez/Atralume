# AtralumeTextarea Use for multiline plain text. Native

rows, cols, maxlength and readonly remain available. resize accepts none,
vertical (default), horizontal or both. There is no auto-resize or rich text
support.

## Import and API

`import { AtralumeTextarea, AtralumeTextareaHarness } from '@atralume/angular/textarea';`

Signal input: resize. Other properties and events belong to the native textarea.

## Forms and validation

Reactive Forms use formControl or formControlName. Template-driven Forms use ngModel and name. Signal Forms use FormField from @angular/forms/signals on the same native control. No custom CVA is registered. The library does not import Signal Forms internally. Set aria-invalid for consumer validation; Angular ng-invalid is styled after touched or dirty. Disabled and readonly remain native properties.

## Accessibility and theming

Keep labels visible, retain focus outlines, and provide persistent instructions. Test keyboard, zoom and screen-reader behavior in your consuming application. Controls support light/dark tokens, standard/glass surfaces, forced colors and reduced motion. Import `@atralume/angular/styles` once for component styles and theme tokens. Override component CSS variables beginning with --atr-comp-form-field- locally; all defaults reference system tokens. The generated token manifest lists the complete contract. No backdrop filtering is applied inside controls.

## States and testing

Explore the sibling stories for default, disabled, checked/readonly, invalid and interaction states. Harnesses use stable native properties, not visual descendants. Use disabled through the form API for reactive controls. Do not duplicate native values or events with custom state.
