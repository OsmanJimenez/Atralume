# Getting Started

Until npm publication, install the tarball produced by `npm pack dist/libs/angular`. Load `@atralume/angular/styles/theme.css`, import `AtralumeButton` from `@atralume/angular/button`, and add `<button atrButton type="button">Continue</button>`.

Select a theme with `data-atr-theme="light|dark|system"`; select glass independently with `data-atr-surface="glass"`. Override semantic tokens on a scope rather than importing internal JSON. Angular 22 is the current peer baseline.
