# Getting Started

Until npm publication, install the tarball produced by `npm pack dist/libs/angular` plus Taiga peers. Call `provideAtralume()` once in the app config, wrap the app shell with `<tui-root>` (portal host for dropdowns, dialogs, and hints), load `@atralume/angular/styles` (or `theme.css`) once, import thin adapters such as `AtralumeButton` from `@atralume/angular/button`, and add `<button atrButton type="button">Continue</button>`.

Brand the whole Taiga surface with scope attributes: `data-atr-theme="light|dark|system"`, `data-atr-surface="glass"`, `data-atr-shape="sharp|rounded|pill"`, `data-atr-brand="green"`. Override semantic tokens on a scope rather than importing internal JSON. Angular 22 is the current peer baseline.
