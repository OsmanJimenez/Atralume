# Accessibility

Critical foreground/background pairs are checked at 4.5:1. Focus uses `:focus-visible` and a shared ring contract. Reduced motion collapses durations, reduced transparency uses opaque surfaces, and forced colors replaces glass and shadows with system colors and visible borders. Native Button semantics remain authoritative.
