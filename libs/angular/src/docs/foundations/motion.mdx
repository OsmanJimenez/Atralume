# Motion

Motion confirms a state change, guides attention, and preserves spatial
continuity. It should start from a stable resting state and never hide an
essential result behind animation.

<Canvas of={Preview.Motion} />

Use the tokenized duration and easing pair. Reduced motion removes the movement
while preserving the resulting state.
