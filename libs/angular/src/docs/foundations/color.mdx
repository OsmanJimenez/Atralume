# Color

Choose color by meaning: primary for actions, containers for persistent
selection, success for completed work, and error for a problem that requires
recovery. A palette is only a source; components consume semantic roles.

<Canvas of={Preview.Color} />

When creating a brand, override the paired foreground and container roles
together. Do not use a brand hue as the only error or selected-state signal.
