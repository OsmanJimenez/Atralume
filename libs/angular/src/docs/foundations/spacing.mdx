# Spacing

The 4px scale creates a repeatable rhythm. Use close values within a control,
larger values between related groups, and the largest intervals when a section
changes subject. The minimum touch target is non-negotiable.

<Canvas of={Preview.Spacing} />

Avoid one-off intermediate values in public components; add a semantic token
only when the decision recurs.
