# Surfaces

Surface treatment is an explicit container decision, not a global preview
mode. Cards, dialogs, popovers, menus, and bottom sheets expose the appearance
that suits their purpose: filled, elevated, outlined, or glass where it has a
meaningful backdrop.

Use a component's documented appearance input when it needs elevation or
transparency. Primary actions retain their brand color so action hierarchy
remains clear on every container treatment.
