# Shape

Shape signals purpose. Use sharp geometry for structural edges, rounded corners
for containers, and full pills only for compact controls such as chips or small
actions—not for every block on the page.

<Canvas of={Preview.Shape} />

Components resolve their radius through semantic shape tokens, so a scoped mode
or component override remains predictable.
