# State

State is behavior made visible. Hover and pressed feedback acknowledge input;
selected states persist; disabled controls remain legible and unavailable.
Never communicate a state with opacity or color alone.

<Canvas of={Preview.State} />

Use state layers over the existing container instead of inventing an unrelated
color for every interaction.
