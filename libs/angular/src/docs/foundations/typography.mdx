# Typography

Typography establishes hierarchy before color or decoration. Display text names
the page, headlines organize content, body text carries the task, and labels
make controls scannable.

<Canvas of={Preview.Typography} />

Use semantic typography roles in components rather than hard-coding individual
font values. This preserves a coherent rhythm as themes evolve.
