# Glass

Glass belongs to a floating container over meaningful visual depth, not a flat
page or a generic button. Its fallback remains opaque and readable when
backdrop filtering is unavailable or transparency is reduced.

<Canvas of={Preview.Glass} />

Use it for Card, Dialog, Bottom Sheet, or Popover where the underlying context
adds information without compromising contrast.
