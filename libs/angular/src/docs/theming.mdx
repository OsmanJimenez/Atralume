# Theming

Atralume is the **brand layer over Taiga UI**. Tokens cascade Reference → System → Component → Consumer override. The token bridge maps `--atr-*` into Taiga’s `--tui-*` theme so every Taiga-backed control follows the brand.

## Modes (scope attributes)

Use on `html` or any nested section. Storybook exposes the same controls in the toolbar.

| Attribute | Values | Effect |
| --------- | ------ | ------ |
| `data-atr-theme` | `light` \| `dark` \| `system` | Color scheme (`system` follows `prefers-color-scheme`) |
| `data-atr-surface` | `standard` \| `elevated` \| `glass` \| `transparent` | Surface treatment (incl. glass) |
| `data-atr-shape` | `sharp` \| `rounded` \| `pill` | Global radius / curve |
| `data-atr-brand` | omit / `green` | Accent palette (example: green primary) |

Bootstrap with `provideAtralume()` and load `@atralume/angular/styles/theme.css` once.

## Manual token overrides

```css
.my-brand {
  --atr-sys-color-primary: #2457d6;
  --atr-sys-color-on-primary: #fff;
}
```

Preserve contrast. Prefer system tokens for semantic themes; use modes for glass, curve, and brand accent across the whole Taiga surface.
