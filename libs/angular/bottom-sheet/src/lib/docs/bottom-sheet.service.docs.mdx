# Bottom Sheet

Bottom Sheet presents temporary content at the lower viewport edge. The service accepts typed data/result like Dialog.

**Ola 5:** composed over Taiga `TuiDialogService` with `appearance: "atr-bottom-sheet"` and CSS that docks the dialog to the bottom edge. `TuiDrawer` remains horizontal-only and is not used as the sheet engine. `mode: "standard"` is retained for API compatibility; Taiga dialogs are modal.

Structural markers (`atrBottomSheetTitle` / `Content` / `Actions` / `Close`) remain Atralume layout helpers.

Taiga UI reference: [Dialog](https://taiga-ui.dev/components/dialog).

## Import and API

Import public components, directives, services and types from `@atralume/angular/bottom-sheet`.

## Accessibility, keyboard and focus

Supply `label` (passed to Taiga dialog). Escape dismisses when `disableClose` is false. Focus returns with the dialog lifecycle.

## Tokens

Import `@atralume/angular/styles/theme.css`. Component tokens use `--atr-comp-bottom-sheet-*`.

```css
.custom {
  --atr-comp-bottom-sheet-shape: 1.5rem;
}
```

```ts
export interface AtralumeBottomSheetConfig<D> {
  data?: D;
  origin?: HTMLElement;
  label?: string;
  labelledBy?: string;
  describedBy?: string;
  role?: "dialog" | "alertdialog";
  disableClose?: boolean;
  autoFocus?: "dialog" | "first-tabbable" | "first-heading";
  restoreFocus?: boolean;
  owner?: DestroyRef;
  injector?: Injector;
  viewContainerRef?: ViewContainerRef;
  contextClasses?: readonly string[];
  closeOnNavigation?: boolean;
  /** Retained for API compatibility; Taiga dialogs are modal. */
  mode?: "modal" | "standard";
}
```
