# Password Field

Password Field is a **recipe**, not a dedicated package. Compose Form Field,
`atrInput`, and Taiga’s password reveal control.

## Import

```ts
import { AtralumeFormField, TuiLabel, TuiTextfield } from "@osmanjimenez/atralume/form-field";
import { AtralumeInput } from "@osmanjimenez/atralume/input";
import { TuiIcon } from "@taiga-ui/core";
import { TuiPassword } from "@taiga-ui/kit";
```

## Minimal example

```html
<atr-form-field hint="Use at least 12 characters.">
  <tui-textfield tuiTextfieldSize="m">
    <label tuiLabel>Password</label>
    <input atrInput type="password" autocomplete="current-password" />
    <tui-icon tuiPassword />
  </tui-textfield>
</atr-form-field>
```

`tui-icon[tuiPassword]` toggles visibility on the sibling password input inside
the same `tui-textfield`. Keep a visible label; do not rely on placeholder alone.

See the Form Field docs for hint/error/density chrome and token overrides.
