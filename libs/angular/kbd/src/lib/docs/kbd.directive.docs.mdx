# Kbd

Styles a native `kbd` element for keyboard shortcut hints. Use it inline next to instructional copy. Prefer the real key labels users see on their platform; do not invent decorative keycaps for non-keyboard actions.

## Import and minimum example

```ts
import { AtralumeKbd, AtralumeKbdHarness } from "@osmanjimenez/atralume/kbd";
```

```html
<p>
  Save with <kbd atrKbd>Ctrl</kbd> + <kbd atrKbd>S</kbd>
</p>
```

## Accessibility

`kbd` conveys keyboard input semantics. Pair shortcuts with visible instructions; do not rely on keycaps alone. Keep contrast against the surrounding surface.

## Customization and component tokens

Styles live in `@osmanjimenez/atralume/styles` under `.atr-kbd` with `--atr-comp-kbd-*` tokens (padding, shape, font, colors). Import `@osmanjimenez/atralume/styles/theme.css` once. Do not create CSS-valued inputs.

```css
.my-example {
  --atr-comp-kbd-container-color: #f0f0f0;
}
```

## Common mistakes

Avoid replacing native semantics or using `kbd` for mouse-only actions. Do not import internal paths or include Storybook in the application runtime. Use the exported harness for observable host state.
