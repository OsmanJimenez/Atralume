# Copy Button

Native button that copies a string to the clipboard. The adapter mirrors Taiga UI `TuiButtonCopy` by composing public `TuiButton` and Angular CDK `Clipboard` (Taiga’s attribute component cannot be used in `hostDirectives` because it ships a template). Uses the clipboard API through CDK; success feedback is exposed via `data-copied` for styling and tests.

Taiga UI reference: [Copy](https://taiga-ui.dev/components/copy).

## Import and minimum example

```ts
import {
  AtralumeCopyButton,
  AtralumeCopyButtonHarness,
} from "@osmanjimenez/atralume/copy-button";
```

```html
<button atrCopyButton type="button" text="npm i @osmanjimenez/atralume">
  Copy install command
</button>
```

## Accessibility

Keep a visible label on the button. After a successful copy, `data-copied` is set for a short interval. Clipboard access can fail in insecure contexts or when permission is denied; provide an alternative when copy is critical.

## Customization and component tokens

Light tokenization lives under `.atr-copy-button` in `@osmanjimenez/atralume/styles`. Import `@osmanjimenez/atralume/styles/theme.css` once. Do not create CSS-valued inputs.

## Common mistakes

Avoid replacing native button semantics or relying on clipboard success without user feedback. Do not import internal paths or include Storybook in the application runtime. Use the exported harness for observable host state.
