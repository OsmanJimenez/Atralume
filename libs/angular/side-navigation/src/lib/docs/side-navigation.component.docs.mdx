# Side Navigation

Composes Taiga `aside[tuiNavigationAside]` + `main[tuiNavigationMain]`. Breaking: custom overlay engine for `mode="over"` removed; open/close is show/hide. `collapsed` maps to Taiga `expanded` inverted.

Taiga UI reference: [Navigation](https://taiga-ui.dev/components/navigation).

Side Navigation composes a container, Taiga aside panel, header, groups, `[tuiAsideItem]` anchors and main content. panelId must be stable and unique. opened is a model; collapsed shrinks the aside rail. `mode` is retained for compatibility but no longer portals.

## Import, API and minimum composition

```ts
import {
  AtralumeSideNavigationContainer,
  AtralumeSideNavigation,
  AtralumeSideNavigationHeader,
  AtralumeSideNavigationContent,
  AtralumeSideNavigationItem,
  AtralumeSideNavigationGroup,
  AtralumeSideNavigationLabel,
} from "@atralume/angular/side-navigation";
```

```html
<button
  type="button"
  (click)="opened=!opened"
  [attr.aria-expanded]="opened"
  aria-controls="workspace-nav"
>
  Toggle navigation</button
><atr-side-navigation-container
  ><atr-side-navigation
    panelId="workspace-nav"
    label="Workspace"
    [(opened)]="opened"
    ><header atrSideNavigationHeader><h2>Workspace</h2></header>
    <section atrSideNavigationGroup>
      <a atrSideNavigationItem href="#overview" active
        ><span aria-hidden="true">⌂</span
        ><span atrSideNavigationLabel>Overview</span></a
      ><a atrSideNavigationItem href="#settings"
        ><span aria-hidden="true">⚙</span
        ><span atrSideNavigationLabel>Settings</span></a
      >
    </section></atr-side-navigation
  >
  Application content remains usable beside the aside.
</atr-side-navigation-container>
```

The exported TypeScript signal inputs and unions are the API contract. Models support two-way binding; projected native controls retain native events. IDs must be unique across the document and identical between server and client. See the sibling stories for states and variants.

## Accessibility, keyboard and focus

Side Navigation composes a container, Taiga aside, header, groups, `[tuiAsideItem]` anchors and `main[tuiNavigationMain]`. panelId must be stable and unique. opened is a model; collapsed shrinks the aside rail. `mode` / `origin` remain for compatibility but no longer portal overlays.

Keep visible names, focus indicators, logical reading order and persistent alternatives for unavailable navigation. Do not use menu or tab roles for ordinary links. Do not attach arbitrary click handlers to noninteractive containers.

## Themes, surfaces and personalization

Import `@atralume/angular/styles/theme.css`. Tokens use `--atr-comp-side-navigation-*` and semantic system defaults. Variants are functional inputs; tokens control brand, shape, spacing and colors. Themes are scoped and surfaces provide context. Instance overrides can live on a consumer class.

```css
.custom {
  --atr-comp-side-navigation-shape: 1.5rem;
}
```

## Responsive, RTL, motion and common mistakes

Logical CSS supports RTL; native navigation retains browser behavior. Components flow or wrap at narrow widths. Overlays constrain themselves to the viewport and safe areas. There is no unnecessary animation; forced colors preserves focus/selection boundaries. Test final application colors, zoom and assistive technology. Do not use CSS-valued inputs or replace native semantics for styling.

## Public TypeScript contract

| Owner                        | Member      | Kind    | Type                  | Default    |
| ---------------------------- | ----------- | ------- | --------------------- | ---------- |
| `AtralumeSideNavigation`     | `panelId`   | `Input` | `string`              | `Required` |

| `AtralumeSideNavigation`     | `opened`    | `Model` | `boolean`             | `true`     |
| `AtralumeSideNavigation`     | `collapsed` | `Input` | `boolean`             | `false`    |
| `AtralumeSideNavigation`     | `origin`    | `Input` | `HTMLElement \| null` | `null`     |
