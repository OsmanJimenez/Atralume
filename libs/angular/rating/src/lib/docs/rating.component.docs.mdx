# Rating

Use Rating for discrete 1…N scores such as reviews or satisfaction. Empty form
values stay `null`; Taiga’s control uses `0` internally and Atralume maps the
two carefully.

Composition over Taiga UI [`TuiRating`](https://taiga-ui.dev/components/rating).

## Import

```ts
import { AtralumeRating } from "@atralume/angular/rating";
```

```html
<atr-rating label="Score" [(value)]="score" [max]="5" />
```

## Forms and validation

Rating implements CVA plus optional required validation. Prefer Reactive Forms,
`ngModel`, or Signal Forms. Disabled and readonly block interaction; required
treats `null` as empty.

## Accessibility

`label` is required and applied as `aria-label` on the host. Keep a visible
caption in surrounding layout when the control is primary content.

## Tokens

Import `@atralume/angular/styles/theme.css` once. Override brand color with
`--atr-comp-rating-active-color` (falls back to `--atr-sys-color-primary`).

```css
.custom {
  --atr-comp-rating-active-color: var(--atr-sys-color-tertiary);
}
```
