# Tree

Composed over Taiga `tui-tree` (`TuiTree`). Blockers for full parity: Taiga expansion is controller/map-based (not `value[]` models); multi-select a11y and the old flat keyboard engine are deferred.

Taiga UI reference: [Tree](https://taiga-ui.dev/components/tree).

`AtralumeTree` maps `AtralumeTreeNode` via `childrenHandler` and shows `tui-tree` in the DOM. Nodes remain immutable consumer data; `selected` / `expanded` models stay Atralume-owned this pass. Use `expandAll` for the Taiga item controller fallback.
