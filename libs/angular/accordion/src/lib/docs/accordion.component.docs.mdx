# Accordion

Use an accordion for short, optional disclosure sections. Atralume styles the
public Taiga host rather than wrapping it: Taiga pairs direct
`button[tuiAccordion]` and `tui-expand` children for disclosure, IDs, and ARIA.

Taiga UI reference: [Accordion](https://taiga-ui.dev/components/accordion).

## Import and composition

```ts
import { TuiAccordion } from "@taiga-ui/kit";
import {
  AtralumeAccordion,
  AtralumeAccordionHeader,
  AtralumeAccordionItem,
  AtralumeAccordionPanel,
} from "@atralume/angular/accordion";
```

```html
<tui-accordion atrAccordion [closeOthers]="true" size="m">
  <button tuiAccordion atrAccordionItem atrAccordionHeader>Profile</button>
  <tui-expand atrAccordionPanel><p>Profile details</p></tui-expand>
  <button tuiAccordion atrAccordionItem atrAccordionHeader>Security</button>
  <tui-expand atrAccordionPanel><p>Security details</p></tui-expand>
</tui-accordion>
```

`atrAccordion` is required on the Taiga host. Buttons and panels must be direct
children, in alternating order. Use `closeOthers` (`true` by default) for one
open panel and `false` for several open panels.

## API, states, and accessibility

The Atralume exports are styling directives. `closeOthers`, `size`,
`[(tuiAccordion)]`, disabled state, and native events remain Taiga/native APIs.
Taiga generates matching panel IDs and supplies `aria-expanded` and
`aria-controls` on each native button. Enter and Space use native button
activation. Keep labels concise and place interactive controls outside headers.

For visual customization, import `@atralume/angular/styles/theme.css` once.
Component tokens use `--atr-comp-accordion-*`, backed by semantic system tokens.

```css
.custom-accordion {
  --atr-comp-accordion-shape: 1.5rem;
  --atr-comp-accordion-padding: 1.25rem;
}
```

Logical spacing supports RTL. The Taiga expand transition respects reduced
motion, and native boundaries and focus remain visible in forced-colors mode.

## Migration from the pre-release wrapper

The pre-release `<atr-accordion>` and `<atr-accordion-item>` components are
replaced by the directives above. This necessary breaking change removes the
extra DOM boundaries that prevented Taiga from pairing triggers and panels.

Do not wrap `button[tuiAccordion]` or `tui-expand` in custom components: doing
so breaks Taiga's direct-child pairing. Do not use CSS-valued inputs, duplicate
native events, or remove accessible names. Test consumer colors, zoom, and
screen readers in the application.
