# Speed Dial

Speed Dial composes a primary native FAB with native action buttons. It exposes opened as a model, orientation and disabled. The main action announces aria-expanded and a stable actions id. Arrow keys, Home/End and Escape manage action focus; disabled actions are skipped. Action or Escape closes and restores focus to the trigger; outside pointer or leaving the group closes without stealing focus from the new target. The group uses constrained in-flow positioning so it remains usable within the consumer viewport layout.

## Import, API and minimum composition

```ts
import {
  AtralumeSpeedDial,
  AtralumeSpeedDialAction,
} from "@atralume/angular/speed-dial";
```

```html
<atr-speed-dial id="create-dial" label="Create"
  ><button atrSpeedDialAction type="button">Document</button
  ><button atrSpeedDialAction type="button">Project</button
  ><button atrSpeedDialAction type="button" disabled>
    Unavailable
  </button></atr-speed-dial
>
```

The exported TypeScript signal inputs and unions are the API contract. Models support two-way binding; projected native controls retain native events. IDs must be unique across the document and identical between server and client. See the sibling stories for states and variants.

## Themes, surfaces and personalization

Import `@atralume/angular/styles/theme.css`. Tokens use `--atr-comp-speed-dial-*` and semantic system defaults. Variants are functional inputs; tokens control brand, shape, spacing and colors. Themes are scoped and surfaces provide context. Instance overrides can live on a consumer class.

}

## Responsive, RTL, motion and common mistakes

Logical CSS supports RTL; native navigation retains browser behavior. Components flow or wrap at narrow widths. Overlays constrain themselves to the viewport and safe areas. There is no unnecessary animation; forced colors preserves focus/selection boundaries. Test final application colors, zoom and assistive technology. Do not use CSS-valued inputs or replace native semantics for styling.
