# OTP Input

Use OTP Input for short numeric one-time codes. The public value is a string
(or `null` when empty). Incomplete codes report `{ otpIncomplete: true }`.

Composition over Taiga UI
[`TuiInputPin`](https://taiga-ui.dev/components/input-pin) inside Form Field /
textfield chrome.

## Import

```ts
import { AtralumeOtpInput } from "@osmanjimenez/atralume/otp-input";
```

```html
<atr-otp-input label="One-time code" [(value)]="code" [length]="6" required />
```

## Forms and validation

OTP Input implements CVA. Required treats empty/`null` as missing. When the
typed length is shorter than `length`, validation returns `otpIncomplete`.
Taiga hardcodes a host `maxlength` of `4` by default; Atralume sets
`[attr.maxlength]` from the `length` input so cell count can grow.

## Accessibility

Keep the visible `tuiLabel`. The control id links the label to the pin input.
Use Form Field `hint` / `error` for supporting text.

## Tokens

Chrome inherits Form Field and textfield tokens. No separate OTP paint tokens
are required beyond brand primary mapping already provided by the Taiga bridge.
