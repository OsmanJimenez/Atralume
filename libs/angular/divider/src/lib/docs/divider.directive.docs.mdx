# Divider

Minimal native separator: `hr` (or a vertical host) plus `--atr-comp-divider-*` tokens. No public Taiga divider primitive exists in `@taiga-ui/core` / `kit` / `layout`, so Atralume keeps a thin tokenized host rather than inventing a parallel engine.

Use `hr` for a thematic horizontal break. A vertical divider uses `orientation="vertical"` on an element such as `div`. Semantic dividers expose `role=separator` and `aria-orientation`; decorative dividers use presentation and `aria-hidden`. Insets use logical directions and work in RTL. Do not use a divider as an interactive resize handle.

## Import and minimum example

```ts
import {
  AtralumeDivider,
  AtralumeDividerHarness,
} from "@atralume/angular/divider";
```

```html
<p>Before</p>
<hr atrDivider />
<p>After</p>
```

## Public API, variants and states

Signal inputs use the exported TypeScript unions. Native attributes and native events remain on the host. Explore the sibling stories for variants, sizes and states.

{/* public-api:start */}

| Input         | Type                 | Default        |
| ------------- | -------------------- | -------------- |
| `orientation` | `DividerOrientation` | `"horizontal"` |
| `inset`       | `DividerInset`       | `"none"`       |
| `decorative`  | `boolean`            | `false`        |

```ts
type DividerOrientation = "horizontal" | "vertical";
type DividerInset = "none" | "start" | "end" | "both";
```

## Accessibility

Keep names meaningful, preserve visible keyboard focus, and check your application at 200% zoom and in forced colors.

## Customization and component tokens

```css
.my-example {
  --atr-comp-divider-inset: 1rem;
}
```

Overrides inherit globally, through nested themes and surfaces, or from a consumer class.
