# Checkbox

Use for independent choices, consent, and selection within a list. A checkbox
may be checked independently of its siblings. Use a radio group for mutually
exclusive choices and a switch for an immediate on/off setting.

## Import

```ts
import {
  AtralumeCheckbox,
  AtralumeCheckboxHarness,
} from "@atralume/angular/checkbox";
import { AtralumeControlLabel } from "@atralume/angular/form-field";
```

```html
<label atrControlLabel>
  <input atrCheckbox type="checkbox" />
  <span>Accept the terms</span>
</label>
```

## API

{/* public-api:start */}

| Input           | Type      | Default |
| --------------- | --------- | ------- |
| `indeterminate` | `boolean` | `false` |

{/* public-api:end */}

The native `checked`, `disabled`, `name`, `value`, and form behavior remain
authoritative. `indeterminate` is a visual DOM state and does not change the
checkbox's submitted boolean value; browsers clear it when a user activates the
control.

## States and keyboard

Space toggles a focused checkbox. A visible label is required; use
`atrControlLabel` to provide the shared control-label treatment and a generous
touch target. Keep validation instructions associated with the control.

## Relation to Taiga UI

`AtralumeCheckbox` is an adapter over Taiga UI `TuiCheckbox`. Consumers keep
using `input[atrCheckbox]`; Taiga supplies the attribute-component behavior and
published styles bridged through Atralume tokens.

## Themes and customization

The public theme stylesheet provides light, dark, system, nested-theme, glass,
forced-colors, and reduced-motion behavior. Checkbox uses the shared
`--atr-comp-form-field-*` token family; override those public CSS custom
properties locally rather than editing package styles.
