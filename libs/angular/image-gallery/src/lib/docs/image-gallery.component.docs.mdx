# Image gallery

`AtralumeImageGallery` composes Taiga carousel movement with `AtralumeImage` state handling and `AtralumeImagePreview` zoom. Use it for a small, ordered media collection or an editorial mosaic of destination-style cards. Do not use it for unbounded feeds.

```ts
import { AtralumeImageGallery } from "@osmanjimenez/atralume/image-gallery";
```

Each image needs a stable `id`, `src`, and `alt`. Optional fields include `title`, `description`, `location`, `tags`, and intrinsic dimensions. `layout` accepts `carousel` (default) or `mosaic`. `activeIndex` is a controlled model and `activeChange` reports navigation. Thumbnails apply to carousel mode; captions and preview are opt-in. An empty collection uses the generic Empty State.

Previous, Next, and thumbnails are native labelled controls. Mosaic tiles keep a clear hierarchy: location, title, description, and tags. The active thumbnail is exposed as a selected tab. Motion is delegated to Taiga and disabled under reduced-motion preferences. Consumer tokens begin with `--atr-comp-image-gallery-*`.
