# Input

Apply to a native text-like `<input>` to add Atralume's form-control styling and
form-field integration without replacing browser semantics or Angular's
ControlValueAccessor. Supported types include text, email, password, search,
tel, url, and number. Do not use it for checkbox, radio, file, range, color, or
button inputs.

## Import and example

```ts
import { AtralumeInput, AtralumeInputHarness } from "@atralume/angular/input";
import { AtralumeFormField } from "@atralume/angular/form-field";
```

```html
<atr-form-field label="Email" hint="Use your work email.">
  <input atrInput type="email" autocomplete="email" />
</atr-form-field>
```

## API

{/* public-api:start */}

Native properties, attributes and events remain the public control API.

{/* public-api:end */}

The native input owns its value, type, validation attributes, events, disabled
and readonly states. Use visible labels and browser autocomplete tokens; a
placeholder is not a label. Native and Angular reactive, template-driven, and
signal forms work on the same input.

## States and keyboard

Keep the browser's native text editing and keyboard behavior. `atr-form-field`
connects its label, hint, and error to the input. Preserve focus indication and
communicate validation in text as well as color.

## Themes and customization

The public theme stylesheet provides light, dark, system, nested-theme, glass,
forced-colors, and reduced-motion behavior. Input uses the shared
`--atr-comp-form-field-*` token family; override those public CSS custom
properties locally rather than editing package styles.
