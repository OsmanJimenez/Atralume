# Taiga UI migration matrix

Inventory of Angular surfaces in `libs/angular` and the playground under the
**brand-layer doctrine** ([ADR-001](./adr/ADR-001-use-taiga-ui-as-component-foundation.md)):

- **Taiga UI** = only UI runtime (behavior, hosts, a11y).
- **Atralume** = tokens, theme bridge, and modes (`data-atr-theme|surface|shape|brand`).
- Thin `atr*` adapters may remain; parallel Atralume UI engines must not.

Statuses (terminal): `migrated` | `composed` | `removed`.  
Work statuses: `pending` | `in-progress`.  
**`exception` is retired** — former exceptions are `pending` until migrated or composed onto Taiga/CDK. Breaking `atr*` APIs is allowed.

Waves: see the [replanned checklist](./taiga-ui-migration-checklist.md).
