# Roadmap

- **Phase 0:** workspace, packaging, Storybook, CI, branches, and Pages.
- **Phase 1:** expanded MD3 tokens, themes, density, motion, and glass.
- **Phase 2:** focused atom catalogue.
- **Phase 3:** molecules and organisms built with Angular Aria/CDK.
- **Phase 4:** npm publication, versioning, and compatibility policy.

Phase 0 intentionally excludes broad component coverage, automated npm publication, Chromatic, and paid services.
