# 0.x to 1.0 planning guide

This guide is intentionally preparatory: Atralume is not yet 1.0. Before a
stable release, each preview API must either be kept unchanged, marked
deprecated with an alternative, or receive a concrete migration entry here.

Consumers should import only documented secondary entrypoints and public style
exports. Imports under `@atralume/angular/internal/*` are unsupported and must
be replaced before 1.0.
